# `src/`

Project source code lives here: ingestion scripts, feature engineering, modeling, evaluation, plotting helpers.

```
src/
  Capstone_data_cleaning/        # scripts that combine raw data and creates processed dataset. Includes data quality checks for Milestone 2.
  EDA/           # exploratory data analysis using processed dataset.
  features/      # create target variables and build features from data/raw/ into data/processed/
  models/        # training, evaluation, and inference
```
